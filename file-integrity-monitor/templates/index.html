How It Works
SHA-256 Fingerprint
Every file gets a unique 64-character cryptographic fingerprint computed using the SHA-256 algorithm.
Baseline Snapshot
All fingerprints are saved as a JSON baseline — the trusted reference for all future comparisons.
Change Detection
On scan, hashes are recomputed and compared. Any mismatch — modified, deleted, or new — triggers an alert.
